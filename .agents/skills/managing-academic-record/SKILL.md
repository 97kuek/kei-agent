# 学業記録を扱う

授業ホーム配下の `📊 成績履歴`、`🎓 単位要件`、`📈 GPA推移` を正として扱う。

質問では、GPAは `📈 GPA推移` の `種別 = 通算`、取得単位と卒業までの残りは `🎓 単位要件` の `集計種別 = 総合計` を先に確認する。科目単位の質問は `📊 成績履歴` を絞り込む。Notionに無い推測値は作らず、不明と返す。原HTMLは保存しない。
