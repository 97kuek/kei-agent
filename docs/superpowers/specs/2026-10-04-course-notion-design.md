# 授業の Notion の作り直し

## 目的

- 授業ホームの DB と列を減らし、どこに何があるかを分かりやすくする
- Dot と Kei Agent が、書き込む先と列の名前で迷わないようにする
- 研究の Notion（`2026-10-04-research-notion-design.md`）と同じ書き方（列名と選択肢は英語、列の順番を決める）にそろえる

## 決めたこと

### 授業ホーム

上から次の順に置く。

1. **授業時間表**（ページ）: 何限が何時から何時か。Dot は授業の時刻をここから換算する
2. **授業**（DB）
3. **課題**（DB）
4. **成績**（DB）
5. **単位要件**（DB）

### 列の順番の決め方

1. 名前のすぐ右に、いちばんよく見る列（状態・成績・残り）
2. 次に、時間（年度・学期・締切）と数字（単位など）
3. 右端に、つながりと照合キー

Notion の DB はこの順に列を作り、表の表示もこの順にそろえる。つながりの戻り側の列は Notion が DB の右端に足すので、順番は表の表示でそろえる。

つながりは片側だけに持つ（課題→授業、成績→授業、成績→単位要件）。授業の DB には戻り側の列を置かない。単位要件の Grades だけは、成績の Requirement の戻り側として置く。

### 授業（DB）

| 列 | 種類 | 中身 |
|---|---|---|
| Name | タイトル | 科目名 |
| Status | 選択 | Taking / Done |
| Year | 数 | 年度。成績と突き合わせる照合キーの一部（Name＋Year＋Term） |
| Term | 選択 | 学期。照合キーの一部 |
| Day | 選択 | 曜日 |
| Period | 数 | 時限 |
| Credits | 数 | 単位 |
| Moodle | URL | Moodle の授業ページ |

### 課題（DB）

| 列 | 種類 | 中身 |
|---|---|---|
| Name | タイトル | 課題名 |
| Status | ステータス | Not started / In progress / Submitted / Overdue |
| Due | 日付 | 締切 |
| Course | つながり（授業） | 科目 |
| Link | URL | Moodle の課題ページ |
| Moodle ID | 文 | Moodle から取り込むときの照合キー。空なら手入力の課題 |

### 成績（DB）

今の「成績履歴」を作り直したもの。

| 列 | 種類 | 中身 |
|---|---|---|
| Name | タイトル | 授業名 |
| Grade | 文 | 成績（A+・A・B…） |
| GP | 数 | GP |
| Credits | 数 | 単位 |
| Category | 文 | 科目区分。大学の成績ページの書き方のまま（単位要件との照らし合わせに使う） |
| Group | 文 | 科目群。大学の成績ページの書き方のまま |
| Course | つながり（授業） | 年度と学期は授業の Year・Term で分かる |
| Requirement | つながり（単位要件） | どの要件に数えたか |
| Record ID | 文 | 成績ページを取り込み直すときの照合キー |

- 取得済みかどうかは、Grade が不可（F）でないことで判断する
- GP のない成績（認定など）は GPA の計算から外す
- 過去の授業の行は、成績ページを取り込むときに、読み取った年度と学期で作る
- GPA は保存しない。学期ごとや通算の GPA を聞かれたら、Dot がこの DB から計算する（GP×単位の合計÷単位の合計）。大学が出す公式の GPA と、小数点以下がずれることがある

### 単位要件（DB）

| 列 | 種類 | 中身 |
|---|---|---|
| Name | タイトル | 要件名（例: 専門選択） |
| Remaining | 数 | 残り単位 |
| Required | 数 | 所定単位 |
| Counted | 数 | 要件に数えた単位 |
| Group | 文 | 大区分（例: 専門科目） |
| Kind | 選択 | Category / Subtotal / Total / Other |
| Grades | つながり（成績） | 数えた成績。成績の Requirement の戻り側 |
| Record ID | 文 | 取り込み直すときの照合キー |

- 既得単位（大学のページにある数字）は取り込まない

### なくすもの

- GPA推移（DB）
- 学習ログ（DB）。勉強時間は共通ホームの「時間記録」（領域＝大学）で持つ
- 消す列: 授業の科目コード・履修年次・必選区分・科目区分・科目群と、授業にあるつながりの戻り側の列（課題・成績履歴・学習ログ・単位要件・GPA推移）、課題の出どころ・見積時間・実績時間・最終同期、成績の取得年度・学期・取得済・取り込み元・GPA推移、単位要件の既得単位・対象授業・取り込み元

## 合わせて直すもの

### Kei Agent（`modules/course/`）

- `notion_setup.py`: 授業ホームの作り（4つの DB の列と順番、選択肢、つながり、授業時間表のページ）
- `notion_sync.py`・`moodle.py`・`ics.py`: Moodle の課題の取り込み（Name・Due・Course・Link・Moodle ID・Status）。出どころは書かない
- `submissions.py`: 提出の確認で Status を Submitted にする
- `academic_sync.py`・`academic_record.py`・`schools/`: 成績ページの取り込み。成績に Category・Group を書き、授業には書かない。GPA推移を書く処理をなくす。単位要件に既得単位を書かない
- `agent.py`・`toggl_report.py` など: 実績時間の集計は時間記録から出す（今も課題の実績時間は読んでいないことを確かめる）
- `src/kei_agent/storage/notion_hub_setup.py`: 共通ホームの週の課題の表が課題の列（締切・状態）を読んでいるので、新しい列名にする
- `tests/` の授業のテストと、`src/kei_agent/testing/fakes.py` の授業の偽物

### Dot（`docs/prompts/`）

- 朝の一覧と Daily: 授業は Status が Taking で今日の曜日の行。時刻は授業時間表で換算する。課題の締切は Status が Submitted・Overdue 以外で Due が今日のもの
- 締切の知らせ: 課題の Status と Due で絞る（Overdue と Submitted を除き、24時間以内と、3日以内で Not started のもの）
- 振り返り: 明日・明後日の締切を課題の Due で集める
- カレンダーの同期: 課題を予定カレンダーに写している部分があれば、新しい列名にする
- 継続指示: 「#2-course」で、成績と GPA の質問は成績の DB から計算して答える。単位の残りは単位要件の Remaining を読む

### 文書

- `docs/agents/course-agent.md` と、授業ホームの作りを書いている箇所

## 移し方

1. 授業ホームの先頭に授業時間表のページを置く（中身は利用者に確認して書く）
2. 4つの DB の列を、名前の変更・選択肢の変更・列の追加で新しい形にする。値は次のように写す
   - 授業の状態: 履修中→Taking、終了→Done
   - 課題の状態: 未着手→Not started、進行中→In progress、提出済み→Submitted、期限切れ→Overdue
   - 単位要件の集計種別: 区分→Category、小計→Subtotal、総合計→Total、その他→Other
3. 成績の科目区分・科目群は、そのまま Category・Group に名前を変える。空のものだけ、つながっている授業の値で埋める
4. 成績履歴の DB の名前を「成績」に、単位要件の DB の名前を「単位要件」にする（絵文字は外す）
5. 値が写ったことを、行の数と中身で古い列と照らし合わせる
6. Dot のプロンプトとリポジトリのコードを新しい形に切り替える
7. 利用者に確認してから、消す列と、GPA推移・学習ログの DB を消す（ゴミ箱に入り、30日間は戻せる）

## 確かめ方

- `uv run python -m pytest` と `uvx ruff check .`
- 切り替えた翌日の朝の一覧で、今日の授業と時刻、今日が締切の課題が出ること
- 締切の知らせが、同じ課題を繰り返さずに出ること
- Moodle の取り込みと提出の確認で、課題の行が2行にならず、Status が変わること
- 成績ページを取り込み直して、成績と単位要件が2行にならないこと
