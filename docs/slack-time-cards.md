# Slack 時間記録カード

`kei-agent-time-cards` を一度実行すると、`10_`（研究）・`20_`（大学）・`30_`（仕事）の各テーマチャンネルに時間記録カードを投稿する。投稿後、Slack で各カードを固定する。

- `開始` は利用者ごとに1本だけ計測する。別チャンネルで開始すると、前の計測をその時刻で止める。
- `20_course` の開始時は、Notion の今学期の「授業」から科目を選ぶ。個別の授業チャンネルは、選んだ科目との対応を記憶する。
- 停止した記録はまず Toggl に送る。成功後、研究は研究ホームの「研究ログ」、大学は授業ホームの「学習ログ」に記録する。仕事は Notion へ書かない。
- 通信失敗はローカルの SQLite に保留し、次の定期確認で再試行する。Toggl の送信結果が不明な場合だけ、重複防止のため Slack の `Togglへ再送` ボタンを使う。

カードの固定は Slack API では管理できないため、初回だけ利用者が行う。
