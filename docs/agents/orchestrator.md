# オーケストレーター

`src/kei_agent/` の Kei Agent 本体。Slackで依頼を受け、担当へ渡し、利用者に一貫した形で返す。ドメイン固有の判断や外部サービスの広い権限は持たない。

## 責務

- Slackイベント、スレッド、App Home、固定時間記録カードの受け口
- 依頼先の選択、A2Aの進捗表示、回答の整形
- 上限到達時の待機・再試行、未完了ジョブと時間記録の再送
- テーマ単位のネットワーク許可、利用者チェック、秘密情報を子プロセスへ渡さない処理

## 境界

オーケストレーターは研究・大学・仕事の回答本文を作り直さない。大学・仕事の外部アカウントには直接触れず、研究Notionは専用Gatewayだけを利用する。失敗時に別providerや別モデルへ黙って切り替えない。

## 設定

App Homeはprovider、モデル、推論強度の一時上書きに使う。providerを切り替えると前のproviderのモデル指定は捨てる。「既定」を選ぶと一時上書き全体を外して設定ファイルのレシピへ戻る。恒久的なモデル世代更新は `config.toml` の `model_recipes` と [モデル運用](../model-policy.md) に従う。
