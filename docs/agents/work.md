# 仕事エージェント

`src/kei_agent_work/`。会社アカウントに接続した Outlook、メール、SharePoint、Teamsの情報を読む。

## 権限

- 予定、メール、資料、Teamsの検索・閲覧だけを行う。
- メール送信、予定作成、Teams投稿、SharePointの作成・変更・共有は行わない。
- 仕事時間はTogglへ記録してもNotionへは書き込まない。

## モデル方針

予定の一覧や構造化済みデータの整形は定型handlerで処理する。メール・資料を横断した要約や判断を含む `ask` は `standard` を既定にする。対外送信や変更を伴う提案は、そもそも実行権限がないためモデルを強くしても実行しない。

モデル世代の更新は [モデル運用](../model-policy.md) の一か所で行う。
