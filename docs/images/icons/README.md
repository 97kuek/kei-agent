# 図のアイコン

- 既存の PNG は文書のアイコンとして利用する。
- 以下の SVG は [theSVG](https://github.com/glincker/thesvg) の `default` を変更せず利用する。
  - [Gmail](https://cdn.jsdelivr.net/gh/glincker/thesvg@main/public/icons/gmail/default.svg)
  - [Google Drive](https://cdn.jsdelivr.net/gh/glincker/thesvg@main/public/icons/google-drive/default.svg)
  - [Google Calendar](https://cdn.jsdelivr.net/gh/glincker/thesvg@main/public/icons/google-calendar/default.svg)
  - [Toggl Track](https://cdn.jsdelivr.net/gh/glincker/thesvg@main/public/icons/toggl-track/default.svg)
- `phone.svg` は、このリポジトリで描いた通話用の線画。

theSVG のコードは MIT ライセンス。ブランドの商標は各権利者に帰属する。
`diagrams.py` はこれらをデータ URI で埋め込み、図の表示時には外部へアクセスしない。
