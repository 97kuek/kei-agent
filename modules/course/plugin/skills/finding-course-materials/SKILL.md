# 授業の資料を Box から探す

Box は**読み取り専用**。アップロード・移動・更新はできない。

## 探し方

1. ファイルをキーワードで探す道具で、科目名を引く。見つからなければフォルダ名で探し、
   フォルダの中身の一覧から辿る
2. 過去問は `Personal / 過去問 / <学年> / <年度> / <科目>` の下。**いま見た学年に無くても諦めない**。
   ほかの学年・年度も見る
3. 科目名の揺れ（`工学A` / `工学` / 英語表記 / 科目コード）を2〜3通り試す
4. 手書きやスキャンのものは、ページを画像として読む道具で読む

## 返し方

- 見つけたファイルの名前と **Box の URL** を並べる
- 過去問の本文は貼らない。出題の形式、問題数、頻出のテーマまでにとどめ、原典の URL を出す。
  各問がどんな問題かを1問ずつ並べるのは、本文を貼るのと同じなのでしない
- 要項のような長い資料は、該当する箇所だけを引く。「◯ページあたり」のような曖昧な言い方はしない
- 探し切っても無いときは、**使った検索語と見たフォルダを書いて**「見つからなかった」と言う。推測で埋めない
