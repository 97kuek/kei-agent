# 課題を確かめる・直す

Notion の「課題」データベースが原典。締切は取り違えると困るので、**必ず読んでから**答える。
道具は `kei-notion`（ゲートウェイ）のものだけ。

## 確かめる

1. `search` で「課題」データベースを見つける（`read` で中身と列を見る）
2. `query` で、締切や状態で絞って読む
3. 科目は「授業」データベースへのリレーションで辿る

## 直す

- 状態の変更（「提出済みにして」など）は `update_page`
- 新しい課題の追加は `create_page`（親は「課題」データベース）
- **Moodle から取り込んだ行は、定期の仕組みが上書きする。** 手で足した行は消さないので、
  取り込み対象の科目かどうかを見てから直す

## 返し方

- 直したページの名前と URL を添える
- 締切は「あと何日」ではなく、日付と時刻で書く
- 提出や登録の代行はしない（できない）。手順を案内するところまで
