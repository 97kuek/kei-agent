# 会社のことを根拠つきで調べる

持っている道具は**読み取り専用**。送信も投稿も作成も更新もできない。

## 探し方

1. メールと Teams のメッセージを、それぞれを検索する道具で、件名・相手・キーワードで引く
2. 資料は SharePoint を検索する道具で引く。フォルダから辿るなら、フォルダを検索する道具で
3. Teams のチャネルの流れは、チームとチャネルの一覧から辿ってメッセージを読む。相手は人を探す道具で確かめる
4. 見つけたものの本文は、本文を読む道具で読む

同じ件でも呼び名が揺れる（案件名・社名・略称）。2〜3通り試してから「無い」と言う。
Teams・SharePoint を読む道具が見当たらないときは（つながっていない provider のとき）、そう伝えて Outlook だけで答える。

## 返し方

- **差出人・日付・件名**（Teams ならチャネルか相手）を必ず添える。原典の URL も出す
- 短いものはそのまま出す。長いものは要点をまとめ、判断に関わるところだけを `>` で引く
- 日付と相手は取り違えると困るので、原典を確かめてから書く
- 件数が多いときは、件数と直近の3件だけを出して「もっと見る？」と聞く
