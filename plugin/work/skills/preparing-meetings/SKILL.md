# 会議の準備をまとめる

## 集めるもの

1. `outlook_calendar_search` で予定（日時、場所、参加リンク、主催者、参加者）
2. 参加者を `search_people` で引き、所属と役割を確かめる
3. `outlook_email_search` と `chat_message_search` で、その件の直近のやりとり
4. `sharepoint_search` で、議題に関わる資料

## 返し方

- 日時・場所・参加リンクを最初に置く（この Slack は依頼者ひとりのものなので、パスコードも出してよい）
- 「前回からの変化」「未回答の論点」「持っていく材料」の3つにまとめる
- 出るべきかどうかの判断は、材料を並べて依頼者に決めてもらう
- 予定の作成・変更はできない。必要なら、そう伝えて手順を案内する
