# 会議の準備をまとめる

## 集めるもの

1. 予定を検索する道具で、予定（日時、場所、参加リンク、主催者、参加者）
2. 参加者を人を探す道具で引き、所属と役割を確かめる
3. メールと Teams のメッセージを検索する道具で、その件の直近のやりとり（本文は本文を読む道具で）
4. SharePoint を検索する道具で、議題に関わる資料
5. 日程を動かす相談なら、空き時間を探す道具で候補を出す

## 返し方

- 日時・場所・参加リンクを最初に置く（この Slack は依頼者ひとりのものなので、パスコードも出してよい）
- 「前回からの変化」「未回答の論点」「持っていく材料」の3つにまとめる
- 出るべきかどうかの判断は、材料を並べて依頼者に決めてもらう
- 予定の作成・変更はできない。必要なら、そう伝えて手順を案内する
