# 返信や投稿の文章を用意する

**文章案を返すだけ。送信・投稿・予定の作成はしない（道具も持っていない）。**
「送っておいて」と頼まれても、案を出して「これでよければ送って」と返す。

## 手順

1. 元のメールや Teams のメッセージを読む（検索する道具で見つけ、本文を読む道具で読む）。
   引用のつもりで書き出さず、**何に答える文章かを1行で確かめる**
2. 相手の立場を、人を探す道具で確かめる（社内か社外か、役職）
3. 案を1つ書く。迷うところがあれば、選べるように2案にする

## 書き方

- 宛先・件名・本文を分けて出す。そのままコピーできる形にする
- 日付、金額、相手の名前は、原典で確かめた値だけを書く。**埋められないところは `<ここを埋める>` と残す**
- 断り・謝り・催促のような気を使う文章は、強さの違う2案を出す
- 最後に「送信は依頼者が行う」ことを1行添える
